Logo mark

The Debate App icon as its own tile: a violet-tinted rounded square holding two speech bubbles. It sits centred above the sign-in card and on the home page.

Overview

Use the logo mark on the landing page and the sign-in screens (default, invalid, error, expired, signed out, submitting). It goes above the heading, once per page, and it is decoration, so it is hidden from assistive technology.

The top bar does not use it. The top bar shows a plain brand link with the same small icon and "The Debate App", described on the top bar page. Do not use the mark as an avatar for Jordan Reyes or anyone else.

Anatomy

  1. TileA grid box that centres the glyph, sized by --size-avatar-xl, with --radius-lg corners and clipped overflow. The mocks tint it with --color-accent-subtle inline.
  2. GlyphThe speech-bubble pair as an inline <svg class="icon icon--lg"> in --color-fg-accent. It is the same glyph the top bar brand uses.
  3. Shadow--shadow-2 lifts the tile off the page so it reads as an icon, not a flat picture.

Variants

Not applicable: there is one logo mark. The mocks do not animate it.

Sizes

The tile is fixed at 64px, which is --size-avatar-xl. It has no small or large form.

64px square, --radius-lg corners.

The glyph is SVG, so it stays crisp on every screen density. The tile size does not change.

States

Not applicable: the logo mark is decorative and cannot be focused, hovered, disabled or loading. It has no motion.

Responsive behaviour

  • The tile stays 64px at every viewport width. It does not scale with the screen.
  • On sign-in it is centred in the card column by .auth-card .logo, so it stays centred from phone to desktop. On the home page it sits above the heading in the page column.

Theming

The tile and glyph read --color-accent-subtle and --color-fg-accent, which are redefined per theme, and the shadow changes with --shadow-2.

Accessibility

Role and pattern

Decorative. The SVG has aria-hidden="true" and the wrapper does too, so a screen reader skips it. The page <h1> names the screen, for example "Sign in".

Keyboard and focus

Not interactive, so it is never in the tab order.

Contrast

The glyph is decoration and carries no information, so no ratio is required. It still clears the non-text minimum:

Glyph on tile

Motion

None. The tile never moves.

Content

  • Never put text inside the tile or draw a caption over it.
  • Never replace the glyph with an emoji. Emoji glyphs are not symmetric, so they sit off-centre in a shape.
  • Keep it decorative with aria-hidden="true". A label would make a screen reader announce the logo above every heading.
