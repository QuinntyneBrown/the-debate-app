Iconography

Twenty-three plain line icons on a 24-unit grid with a 2px stroke, coloured by the text beside them, each with one meaning.

Overview

The Debate App uses 20 line icons, drawn inline as SVG so they inherit text colour and need no icon font or sprite request. Each icon means exactly one thing everywhere it appears. Icons stay plain and functional; the writing carries the personality.

Style

  • Grid: 24 × 24 viewBox, about 2px of padding inside it.
  • Stroke: 2 units, round caps and joins, no fill (.icon sets fill: none; stroke: currentColor).
  • Colour: currentColor, so an icon is always the colour of the text beside it; alerts and toasts set it from their *-icon tokens.
  • Markup: <svg class="icon" aria-hidden="true" viewBox="0 0 24 24"> with paths only; no width, height or fill attributes.

Sizes

sm 16px beside small text (save status, helper text); md 20px default (buttons, alerts, menus, toasts; inside buttons it is 1.25em); lg 24px in the brand mark, the date badge and empty states.

Labelling

  • An icon beside visible text is decoration: aria-hidden="true", and the text is the name.
  • An icon-only button (close, edit, remove) has aria-label with the verb and the object: "Edit meeting", "Delete meeting", "Dismiss", "Close".
  • An icon that carries status (the cloud-off icon on a failed load) always sits next to words ("We couldn’t load the meetings").

Usage

  • Lead with the icon in buttons and menu items; the label follows.
  • Use one icon per meaning: the check is "done", the check in a circle is "success"; do not swap them.
  • Never use an emoji where an icon has a job (close, back, retry), and never use an icon as decoration with no meaning.
  • Copy paths from this sheet; do not redraw or import icons from another set.

Accessibility

  • Meaningful icons reach 3:1 against their background (1.4.11); the toast icons have dedicated tokens for this.
  • Icon-only buttons are at least 24px (--target-min) and usually 44px.
  • In forced-colours mode icons follow currentColor and stay visible.
