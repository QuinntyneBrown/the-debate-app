Shape

Soft corners scaled to the object, two border widths, and the fixed sizes for avatars and image thumbnails.

Overview

The Debate App is soft but orderly: 12px corners on fields and menus, 24px on cards and dialogs, 32px on bottom sheets, and full pills for buttons, badges and avatars. One radius per size keeps it from looking random. This page also holds the fixed sizes for avatars and image thumbnails.

Radius scale

--radius-md
--radius-lg
--radius-xl
--radius-full
RadiusUse it for
--radius-xsCheckboxes, documentation swatches
--radius-smSmall thumbnails, menu items, skeleton lines, close buttons, editor toolbar buttons
--radius-mdText fields, menus, alerts, toasts, the rich-text editor frame, larger thumbnails
--radius-lgCards, the meeting list, dialogs from 640px, logo tile
--radius-xlTop corners of a bottom sheet (dialogs under 640px)
--radius-fullButtons (pills), the floating top bar, badges, avatars, swatches

Rule of thumb: the bigger the object, the bigger the radius, and a child's radius is never larger than its parent's. A 44px field gets 12px; a button or a 24px badge is a pill; a card gets 24px so the 12px editor frame inside it never looks rounder than its parent.

Border widths

--border-width-hairline
--border-width-thick
  • Hairline (1px) for every edge: cards, fields, dividers, list rows, buttons.
  • Thick (2px) for edges that carry state: the selected tab indicator, the button spinner, the toast timer, the hover ring on an avatar button and a hovered link's underline.
  • The focus ring has its own width, documented in Accessibility.

Avatar and thumbnail sizes

J J JR
Avatar sm 32px (top bar), md 40px (lists, dialog icons), lg 56px (account), xl 64px (empty-state icons).

Usage

  • Use the radius token for the component's size; never mix radii inside one component (the bottom sheet is the one exception: rounded top, square bottom against the screen edge).
  • Never type border-radius: 50% or 9999px; use --radius-full.
  • Never set 1px or 2px borders by hand; use the border-width tokens.
  • Avatars and thumbnails come in the four sizes above only. The --size-cover-* tokens keep their historical names but are a generic thumbnail scale; the current mocks use avatars only.
