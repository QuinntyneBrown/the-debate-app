Responsive

Designed at 360px first, then given columns, navigation and room at 640, 768 and 1024px, with every control sized for a thumb.

Overview

Members check the meeting list on a phone before the evening; organisers edit meetings on a laptop. Every screen is designed at 360px first and gains space, columns and navigation as the window grows. Breakpoints and grid tokens are on Layout.

Mobile-first rules

  • Base CSS is the phone layout. Add to it with @media (min-width: 40rem | 48rem | 64rem); never undo a desktop layout with max-width.
  • Prefer intrinsic layouts that need no query: .cluster wraps, .grid--auto fills, flex-wrap on button rows.
  • Spacing and type do not scale with the viewport; only --layout-gutter, --layout-margin and --layout-columns change.
  • Use 100dvh for full-height screens and env(safe-area-inset-bottom) for anything fixed to the bottom.

Touch and pointer

  • Every control is at least 44px tall (--control-height-md); small buttons (36px) only appear in rows that are spaced 8px or more apart.
  • Nothing depends on hover. Hover lifts and row highlights are extras; the same information is visible without them.
  • No gestures are required: there is no swipe-to-dismiss, no drag, no long press. Every toast and banner has a close button.
  • The editor toolbar buttons are 36px with 4px gaps and sit inside a toolbar that wraps; nothing requires a pointer.
  • (pointer: coarse) is not used to grow targets; they are already large.

Testing matrix

ViewportStands forCheck
320 × 640Smallest phone, 400% zoomNo sideways scroll, nothing clipped

768 × 1024Tablet8 columns, centred dialogs

Each in light and dark, in Chromium only (the target browser is the latest Chrome). The mocks' screenshot_mocks.py captures 360, 768 and 1280 in both themes; it also works on this folder with --out.

Accessibility

  • Reflow (1.4.10) at 320px; orientation (1.3.4) is never locked.
  • Target size (2.5.8): 24px minimum everywhere, 44px for primary actions.
  • Focus not obscured (2.4.11): the sticky top bar is accounted for with scroll-padding-top.
  • Consistent navigation (3.2.3): the same primary links in the same order at every width.

Tokens

This page owns no tokens. Colour tokens are on Color, layout tokens on Layout, motion on Motion, and the interaction tokens (targets, control heights, focus ring) on Accessibility.
