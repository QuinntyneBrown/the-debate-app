Lists and tables

The Debate App's one collection, meetings, is shown whole as a list of rows grouped by Upcoming and Past, with no paging, sorting, filtering or selection.

Overview

The Debate App has one collection: meetings. They are shown as a list of rows grouped under "Upcoming" and "Past", soonest first, with no paging, sorting, filtering or selection. Each row opens the meeting, and its icon buttons edit or delete it. There are no data tables.

  • One row, one meeting. Date badge, title, when, and a one-line excerpt of the abstract.
  • Grouped by time. A group heading uses the overline style and an h2; empty groups are left out.
  • The title is the link. The edit and delete buttons are icon-only and named with the meeting title.

When to use

Use a list for any short collection of things a person scans and opens. If a future collection needs comparing across columns, add a table pattern then; none of the current mocks need one.

Structure

A ul.list.card.card--flush holds li.meeting rows. The date badge is decorative; the full date appears in the "when" line so the information is not repeated for assistive tech.

Responsive

  • On phones the excerpt wraps under the title and is limited to two lines with an ellipsis; the full text is in the title attribute and on the meeting page.
  • Long titles wrap rather than truncate; the date badge and action buttons keep their size.
  • From 768px the excerpt sits on one line and the action buttons stay at the right edge.

Accessibility

  • A real <ul> with <li> items, so screen readers announce the item count.
  • The date badge is aria-hidden; the "when" line holds the same date in words.
  • Icon buttons carry aria-label with the verb and the full title: "Edit Universal basic income".
  • Group headings are real headings so people can jump between Upcoming and Past.
  • Hover highlights are an extra; every row action is reachable by keyboard and has a visible focus ring.
  • The loading list is aria-busy="true" with a label; skeleton rows are aria-hidden.

Content

  • Title is the motion or the meeting name as typed by the organiser.
  • When is "Tomorrow · 7:00 pm–8:30 pm" within a week, otherwise "Tue 27 Oct · 7:00 pm–8:30 pm".
  • Excerpt is the abstract text, trimmed with an ellipsis; if there is none, "No abstract yet" in muted text.
  • Subtitle counts: "2 upcoming · next is tomorrow at 7:00 pm".
