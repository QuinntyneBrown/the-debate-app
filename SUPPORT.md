# Support

## Getting help

- Read the [README](README.md) and the [docs](docs).
- Search existing [issues](../../issues) to see whether your question has been answered.

## Reporting bugs and requesting features

Open a [new issue](../../issues/new/choose) using the appropriate template.

## Security issues

Do not use public issues. See [SECURITY.md](SECURITY.md).

## Support expectations

This project is maintained on a best-effort basis and there is no guaranteed response time.
